# plus-minus
Python/Django based side project developed by Terry Chu.

## Getting started

1. Create and activate a virtual environment if you want one.
2. Install dependencies:
   `python3 -m pip install -r requirements.txt`
3. Run the app:
   `python3 manage.py runserver`
4. Open the project at http://127.0.0.1:8000/ to use the plus/minus calculator.

The project includes a Django poll app and a basketball field-goal calculator in the `plusminus` app.
